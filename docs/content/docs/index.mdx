Ledger is a Go library for usage-based billing in SaaS products. You define **plans** and a feature catalog, subscribe your tenants, meter **usage**, check **entitlements** and quotas on the request path, and generate **invoices** with tiered pricing and coupons.

It's a library, not a service. It runs inside your process against your own database (PostgreSQL, SQLite, MongoDB or the in-memory store), and you keep `main`, the connection and the HTTP server. Ledger doesn't charge cards: it works out what a tenant owes and tracks the invoice's state, and collecting the money is the job of a payment provider you plug in.

## The billing model

| Component | What it represents | Go type |
|-----------|-------------------|---------|
| Plan | What you sell: features, limits, a base fee and price tiers | `plan.Plan` |
| Plan feature | One thing a plan grants: a metered quota, a seat count or an on/off flag | `plan.Feature` |
| Catalog feature | A reusable feature definition, kept apart from any plan | `feature.Feature` |
| Subscription | A tenant on a plan, with its current billing period | `subscription.Subscription` |
| Usage event | One metered unit of work | `meter.UsageEvent` |
| Entitlement result | The answer to "can this tenant use this feature right now?" | `entitlement.Result` |
| Invoice | What a tenant owes for one period, as line items | `invoice.Invoice` |
| Coupon | A percentage or fixed-amount discount | `coupon.Coupon` |
| Provider | Your bridge to a payment gateway | `provider.Provider` |

## What it does

- Usage metering: `Meter` drops an event into a buffer that a background worker flushes to the store in batches, so the call never waits on the database.
- Quota checks: `Entitled` and `Remaining` answer from the tenant's active subscription and its plan, with hard or soft limits and `-1` for unlimited. Results are cached in the store for 30 seconds by default.
- Pricing: a base fee plus graduated, volume or flat tiers per feature, with seat features billed per seat.
- Subscription lifecycle: trials, plan changes, pause and resume, scheduled or immediate cancels, and a lifecycle clock that rolls periods forward, enacts cancels, ends trials and marks overdue invoices past due.
- Invoices: `GenerateInvoice` builds base, overage, seat, discount and tax lines for a period. You call it; Ledger never bills a period on its own.
- Plugins: typed hooks for plan, subscription, usage, entitlement, invoice and provider events, plus strategy plugins for pricing, usage aggregation, tax, export formats and coupon validation.
- TypeIDs: every entity gets a prefixed, K-sortable ID (`plan_`, `sub_`, `inv_`, `cpn_` and so on).
- Exact money: `types.Money` holds integer minor units, with overflow-checked arithmetic.

## Quick look

This program uses the in-memory store, so there's nothing to install:

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/xraph/ledger"
	"github.com/xraph/ledger/plan"
	"github.com/xraph/ledger/store/memory"
	"github.com/xraph/ledger/subscription"
	"github.com/xraph/ledger/types"
)

func main() {
	ctx := context.Background()

	engine := ledger.New(memory.New())
	if err := engine.Start(ctx); err != nil {
		log.Fatal(err)
	}
	defer engine.Stop()

	pro := &plan.Plan{
		Name:     "Pro",
		Slug:     "pro",
		Currency: "usd",
		Status:   plan.StatusActive,
		AppID:    "my-app",
		Features: []plan.Feature{
			{Key: "api_calls", Name: "API calls", Type: plan.FeatureMetered, Limit: 10000, Period: plan.PeriodMonthly},
		},
		Pricing: &plan.Pricing{
			BaseAmount:    types.USD(4900), // $49.00
			BillingPeriod: plan.PeriodMonthly,
		},
	}
	if err := engine.CreatePlan(ctx, pro); err != nil {
		log.Fatal(err)
	}

	sub := &subscription.Subscription{TenantID: "acme", AppID: "my-app", PlanID: pro.ID}
	if err := engine.CreateSubscription(ctx, sub); err != nil {
		log.Fatal(err)
	}

	// Entitled and Meter read the tenant and app from the context.
	ctx = context.WithValue(ctx, "tenant_id", "acme")
	ctx = context.WithValue(ctx, "app_id", "my-app")

	res, err := engine.Entitled(ctx, "api_calls")
	if err != nil {
		log.Fatal(err)
	}
	if res.Allowed {
		if err := engine.Meter(ctx, "api_calls", 1); err != nil {
			log.Fatal(err)
		}
	}
	fmt.Println("allowed:", res.Allowed, "remaining:", res.Remaining)
}
```
